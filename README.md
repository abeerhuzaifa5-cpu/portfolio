## 🚀 Run locally

Just open `index.html` in a browser, or serve it:

```bash
# Python
python3 -m http.server 8000

# or Node
npx serve .
```

Then visit http://localhost:8000

## 🌐 Deploy on GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch** → `main` → `/ (root)`.
4. Save. Your site goes live at `https://<username>.github.io/<repo>/`.

## ✏️ Customise

- **Contact form**: currently a front-end demo. To make it live, point it at a form service
  (Formspree, Web3Forms, etc.) or your own API endpoint in `script.js`.
- **Colors**: edit the CSS variables in `:root` in `styles.css`.
